# 스크린샷 상태

`web-previews/`는 아래 명령으로 생성하는 웹 레이아웃 확인용 시안 폴더입니다. 생성된 이미지는 Git에 포함하지 않습니다. 예시 루틴과 예시 기록은 캡처용 브라우저에만 주입하며 앱 기본 데이터나 사용자 저장소를 변경하지 않습니다.

**iOS 기기/시뮬레이터 캡처가 아니므로 App Store 제출용 완료 자료로 취급하지 마세요.** 실제 iOS 빌드에서 다시 캡처하고 최신 App Store Connect 요구 규격을 확인해야 합니다.

| 대상             | 준비한 시안                        | 실제 제출 전                                      |
| ---------------- | ---------------------------------- | ------------------------------------------------- |
| iPhone 대형 화면 | 1320×2868px 캘린더·기록창·통계 3종 | 지원 iPhone 시뮬레이터 또는 실제 기기에서 재캡처  |
| iPad 대형 화면   | 2064×2752px 같은 3종               | iPad 지원이 켜져 있으므로 iPad 실제 렌더링 재확인 |

재생성: 개발 서버를 8082번 포트에서 실행한 뒤 `node scripts/capture-release-previews.mjs`를 실행합니다. 다른 포트는 `PREVIEW_BASE_URL`로 지정합니다. 캡처 파일에 기기 프레임, 가짜 상태 표시줄 또는 실제 기기라고 주장하는 표시는 넣지 않았습니다.

최종 캡처 체크: 실제 버전과 일치하는 UI, 키보드/안전 영역/모달 확인, 개인 데이터 제거, 잘리지 않는 텍스트, 모든 필수 기기 크기, 한국어 현지화, App Store Connect 업로드 후 미리보기 확인.
