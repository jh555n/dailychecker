# Daily Checker 지원 페이지 초안

게시 전 소유자가 지원 웹사이트와 공개 연락 창구를 결정해야 합니다. 개인 연락처를 임의로 공개하지 않습니다.

## 기록은 어디에 저장되나요?

기기의 앱 저장소에 보관됩니다. 계정, 앱 자체의 클라우드 백업, 다른 기기와의 동기화는 없습니다. 기기 백업 설정에 따라 운영체제의 백업에 포함될 수 있습니다.

## 연속일이 0일이 된 이유는 무엇인가요?

NO 또는 지나간 미기록일에서 연속 기록이 끊깁니다. 오늘 아직 입력하지 않았다면 어제까지의 연속일을 유지합니다. 잘못 입력했다면 캘린더에서 해당 날짜를 골라 수정하세요.

## 루틴이나 기록을 삭제하려면 어떻게 하나요?

해당 날짜의 기록창에서 선택을 해제하고 저장하거나, 루틴 관리에서 루틴을 삭제하세요. 루틴 삭제는 해당 루틴의 모든 기록을 함께 삭제합니다.

## 저장이 안 되거나 기록을 불러오지 못하면 어떻게 하나요?

기기 저장 공간을 확인한 뒤 다시 시도하세요. 기존 기록을 보존하려면 앱 삭제나 데이터 초기화를 먼저 하지 마세요. 현재 버전은 손상된 저장 데이터를 자동으로 덮어쓰지 않습니다.

문의할 때는 앱 버전, iOS 버전, 발생 화면과 재현 단계를 전달하세요. 민감한 루틴 내용이나 다른 개인정보는 필요한 경우가 아니라면 보내지 마세요. 실제 문의 방법은 운영자가 확정한 뒤 이 페이지에 추가해야 합니다.
